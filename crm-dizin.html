  • Sayfa tipi — kartın .t rozetinde zaten var (liste/detay/form/rapor/hub/konsol/kiosk/çıktı vb.).
  • Faz 1 aktif / Faz 2 kilitli / Faz 3 planlı mı — kartın Faz + Durum rozeti BİRLİKTE cevaplıyor (ör. "Faz 2" + "Hazır" = hazırlık, açık; "Faz 2" + "Faz 2 Kilitli" = gerçekten kilitli önizleme; "Faz 3" + "Faz 3 Planlı" = henüz inşa edilmedi, ortak vitrin ekranı üzerinden temsil).
  • Eksik durum — kartın Durum rozetinde ("Eksik" etiketi taşıyan satır bu envanterde YOK — 0/190).
  • Veri kaynağı — Panel & Kontrol'ün 7 ekranı için modül eşlemesi zaten tasks/spec/panel-veri-kaynagi.md'de var (burada TEKRAR ÜRETİLMEDİ — o dosyaya bakın). Diğer 183 ekranda veri kaynağı kendi modülünün mock verisidir (kartın Modül rozeti = kaynak modül); üretimde ilgili modülün backend servisinden gelecektir.
  • Backend ihtiyacı / API ihtiyacı — TÜM 190 ekran için AYNI, tek doğru cümle: bu prototip backend'siz statik HTML/JS/CSS'tir (CLAUDE.md, "Backend YOK, veritabanı YOK"); üretim sürümünde HER modül kendi REST/GraphQL servisini gerektirecektir. Ekrana özel bir API şeması bu turda tanımlanmadı — icat edilecek bir bilgi olduğu için uydurulmadı.
